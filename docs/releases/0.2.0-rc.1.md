# Lobster Quant Agent 0.2.0-rc.1 — release candidate notes

Status: **historical source tag; no GitHub Release or package publication**

This candidate was stopped before Release publication because its Python package still declared `__version__ = "0.1.0"`. The public `v0.2.0-rc.1` tag is retained as history and must not be moved or overwritten. The forward correction is `0.2.0-rc.2`.

## Summary

This candidate prepares Lobster Quant Agent for reviewable ClawHub distribution and improves the first-run story without changing its core boundary: it is an OpenClaw-only market-research, alert, and backtesting plugin with no broker connection or order execution.

## Highlights

- Bilingual README with direct A-share/US-market, alert, backtest, Telegram/WeChat/QQ, privacy, and no-trading explanations.
- Reproducible synthetic SVG demo with its JSON source and generator.
- Scoped ClawHub package identity and the current required compatibility/build/install metadata.
- Dependency-free packaged HTTP core plus graceful labeling when the optional AkShare source is unavailable.
- Offline first-use smoke test and npm payload assertions.
- Privacy-focused feedback forms, community launch drafts, adoption metrics, and release gates.

## Upgrade notes from 0.1.0

- No runtime-state migration is expected.
- Existing `plugins.entries.lobster-quant-agent.config` keys remain unchanged.
- Existing source installations can pull the reviewed release and rerun `./scripts/install.sh` after backing up their private local state directory.
- The ClawHub package name is `@cnan5336-dev/lobster-quant-agent`; the OpenClaw plugin id remains `lobster-quant-agent`.
