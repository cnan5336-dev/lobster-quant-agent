# Lobster Quant Agent 0.2.0-rc.2 — release candidate notes

Status: **local draft; not released**

## Why rc.2 exists

The public `v0.2.0-rc.1` source tag was stopped before a GitHub Release or package publication because `package.json` and `openclaw.plugin.json` declared `0.2.0-rc.1` while the Python package still declared `__version__ = "0.1.0"`.

This forward-only candidate aligns the package, plugin manifest, lockfile, and Python version at `0.2.0-rc.2` and adds validation that fails if those version surfaces drift again. It does not move or overwrite `v0.2.0-rc.1`, and it adds no trading or broker capability.

## Candidate highlights

- Bilingual README covering A-share/US-market research, alerts, backtests, Telegram/WeChat/QQ, privacy, and the no-trading boundary.
- Reproducible synthetic SVG demo with its JSON source and generator.
- Scoped ClawHub package identity and required compatibility/build/install metadata.
- Dependency-free packaged HTTP core plus explicit gaps when optional AkShare workflows are unavailable.
- Offline first-use smoke tests, managed `npm-pack` acceptance, payload assertions, and fail-closed notification checks.
- Privacy-focused feedback forms, community launch drafts, adoption metrics, and release gates.

## Upgrade notes from 0.1.0

- No runtime-state migration is expected.
- Existing `plugins.entries.lobster-quant-agent.config` keys remain unchanged.
- Existing source installations can pull the reviewed release and rerun `./scripts/install.sh` after backing up their private local state directory.
- The future ClawHub package name is `@cnan5336-dev/lobster-quant-agent`; the OpenClaw plugin id remains `lobster-quant-agent`.

## Compatibility

- OpenClaw/plugin API `>=2026.5.17`
- Node.js `>=22.22.3`
- Python `>=3.10`
- macOS and Linux target; Windows unsupported in this candidate

At candidate validation time, `npm audit --omit=peer` reported zero known vulnerabilities for the plugin package's installed dependencies. A full development or host dependency-tree audit may still report advisories inherited from the peer-supplied OpenClaw runtime and its upstream transitive dependencies; those packages are not bundled in this plugin package. Keep OpenClaw current and review its upstream security advisories as part of host maintenance.

See [COMPATIBILITY.md](../../COMPATIBILITY.md) for tested versus untested environments.
