# Lobster Quant Agent 0.2.0 — stable release notes

`0.2.0` is the stable promotion of the validated `0.2.0-rc.2` line. It changes release metadata and installation status only; it does not add runtime features, broker connectivity, or order execution.

## Highlights

- OpenClaw-only A-share and delayed US-market research, alerts, reports, and historical backtesting.
- Explicit fail-closed notification delivery when a private channel target is missing.
- Local private state outside the repository for watchlists, holdings labels, caches, alert state, and generated backtests.
- Bilingual setup documentation and a reproducible synthetic demo containing no real account, holding, watchlist, notification target, or live result.
- Scoped ClawHub code-plugin packaging with version-consistency, payload, privacy, and clean-install validation.

## Promotion from rc.2

- Package, plugin manifest, lockfile, and Python version surfaces now consistently report `0.2.0`.
- Existing `v0.2.0-rc.1` and `v0.2.0-rc.2` tags remain immutable.
- Configuration keys and runtime-state formats are unchanged from rc.2; no state migration is expected.

## Install

```bash
openclaw plugins install clawhub:@cnan5336-dev/lobster-quant-agent
```

OpenClaw `>=2026.5.17`, Node.js `>=22.22.3`, and Python `>=3.10` are required. macOS and Linux are supported; Windows is not supported because the monitor relies on POSIX file locks.

## Compatibility and known limitations

- OpenClaw is the only supported runtime. The Python CLI is an internal deterministic test and plugin layer, not a standalone supported product.
- Public market sources may be delayed, stale, rate-limited, unavailable, or changed upstream. Backtests are simplified research simulations, not execution-quality performance records.
- Real Telegram, WeChat, and QQ delivery requires user-owned OpenClaw channel configuration and an explicit private notification target; no real channel credentials or delivery targets are included or tested by the package.
- The plugin package's runtime dependency audit reports zero known vulnerabilities. A full development or host dependency-tree audit may still report advisories inherited from the peer-supplied OpenClaw runtime and its upstream transitive dependencies; those dependencies are not bundled in this plugin package. Keep OpenClaw current and review its upstream security advisories as part of host maintenance.

See [COMPATIBILITY.md](../../COMPATIBILITY.md), [SECURITY.md](../../SECURITY.md), and [DISCLAIMER.md](../../DISCLAIMER.md).

- No claim of existing adoption, endorsements, investment performance, or guaranteed availability of upstream market data.
