# Screenshot placeholders

Real chat screenshots are intentionally excluded from the public repository because they can expose channel identities, holdings, watchlists, and account metadata.

Future documentation contributors may add fully synthetic captures for:

- Telegram morning report
- WeChat post-market review
- QQ compact alert
- Natural-language backtest summary and HTML chart

Before adding an image, verify that it contains no real names, usernames, chat ids, account ids, tokens, holdings, watchlists, timestamps tied to a person, or local filesystem paths.
