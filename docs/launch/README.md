## Shared claims policy

- Say what the project does and what was actually tested.
- Always state: OpenClaw-only, research/alerts, no broker connection, no order execution, local private state, and delayed/incomplete data risk.
- Label the demo as synthetic.
- Never invent stars, downloads, users, ratings, testimonials, endorsements, revenue, performance, or returns.
- Treat goals as `TARGET`, not current results.
- Never paste real credentials, chat/account ids, notification targets, holdings, watchlists, logs, screenshots, or generated user results.

## Platform checks before posting

- r/openclaw currently reserves standalone Showcase/Skills posts for Saturday–Sunday and asks for the correct flair; re-check the live sidebar immediately before posting.
- OpenClaw Discord channel names and promotion rules can change; select the current maintainer-approved showcase/plugin channel and avoid cross-posting duplicates.
- Re-check V2EX node and title rules before posting.
- Show HN requires something people can actually try, asks makers to remain available for discussion, and forbids asking others to upvote. Do not post until the install path is public and verified.
